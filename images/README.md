Déposez ici les photos produits du site.

## Fichier attendu

| Fichier | Utilisé par | Description |
|---|---|---|
| `syfir-planteur.png` | Carte « Syf Planteur™ » (index.html) | Photo du sachet SYFIR Saveur-Planteurs |

Tant que le fichier n'est pas présent, le site affiche automatiquement une
photo d'ambiance de remplacement (aucune image cassée ne s'affichera).

## Comment ajouter l'image

1. Sur GitHub, ouvrez ce dossier `images/`.
2. Cliquez sur **Add file → Upload files**.
3. Glissez votre photo et renommez-la exactement `syfir-planteur.png`.
4. Validez (« Commit changes ») — la photo apparaît sur le site.

Conseil : une image carrée ou légèrement verticale, environ 700 px de large,
sur fond clair ou en situation (plage, table, golden hour) rendra le mieux.
